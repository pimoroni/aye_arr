# Aye Arr - MicroPython Examples <!-- omit in toc -->

This directory contains MicroPython examples for the Aye Arr library.

## Board Examples

Here are a number of demos of the Aye Arr library controlling the hardware features of various Pimoroni / RP boards:

### Pimoroni

* [Pico Motor Shim](boards/motor_shim)
* [Plasma 2350](boards/plasma)
* [Tiny 2350](boards/tiny_2350)
* [Tiny FX](boards/tiny_fx)

## NEC Examples

These are functional examples of the NEC protocol of the Aye Arr library, which can be used on any Pico/RP board with an infrared transmitter or receiver connected. Use these to understand how to interact with the API and adapt to your own projects:

* [Send](nec/send)
* [Receive](nec/receive)
