# Aye Arr - Plasma 2350 (W) - MicroPython Examples <!-- omit in toc -->

These are micropython examples for using Aye Arr with the [Pimoroni Plasma 2350](https://shop.pimoroni.com/products/plasma-2350) and [Pimoroni Plasma 2350 W](https://shop.pimoroni.com/products/plasma-2350-w)

## Examples

### Colour Control (RGB)
[colour_control_rgb.py](colour_control_rgb.py)

Set the colour of a RGB LED strip connected to Plasma 2350 using the number buttons on the Pimoroni Aye Arr Remote.


### Colour Control (HSV)
[colour_control_hsv.py](colour_control_hsv.py)

Set the colour of a RGB LED strip connected to Plasma 2350 using the number buttons on the Pimoroni Aye Arr Remote, and change its hue, saturation, and value using the directional buttons.


### Colour Control Expanded (RGB)
[colour_control_expanded_rgb.py](colour_control_expanded_rgb.py)

Set the colour of a RGB LED strip connected to Plasma 2350 using the number buttons on the Pimoroni Aye Arr Remote, and change it using the Red-Cyan, Green-Magenta, and Blue-Yellow button pairs. This also plays a rainbow effect, and includes saving and loading of settings.
