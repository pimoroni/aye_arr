# Aye Arr - Tiny 2350 - MicroPython Examples <!-- omit in toc -->

These are MicroPython examples for using Aye Arr with the [Pimoroni Tiny 2350](https://shop.pimoroni.com/products/tiny-2350).

- [Examples](#examples)
  - [LED Control (RGB)](#led-control-rgb)
  - [LED Control (HSV)](#led-control-hsv)
  - [LED Control Expanded (RGB)](#led-control-expanded-rgb)


## Examples

### LED Control (RGB)
[led_control_rgb.py](led_control_rgb.py)

Set the colour of Tiny 2350's onboard RGB LED using the number buttons on the Pimoroni Aye Arr Remote.


### LED Control (HSV)
[led_control_hsv.py](led_control_hsv.py)

Set the colour of Tiny 2350's onboard RGB LED using the number buttons on the Pimoroni Aye Arr Remote, and change its hue, saturation, and value using the directional buttons.


### LED Control Expanded (RGB)
[led_control_expanded_rgb.py](led_control_expanded_rgb.py)

Set the colour of Tiny 2350's onboard RGB LED using the number buttons on the Pimoroni Aye Arr Remote, and change it using the Red-Cyan, Green-Magenta, and Blue-Yellow button pairs. This also plays a rainbow effect, and includes saving and loading of settings.
