# Changelog

1.0.1
-----

* A second receiver or sender on one PIO no longer fails on RP2350, the PIO's GPIO base now being set only where it differs
* package.json no longer lists files missing from the repository, so it installs with `mip`
* Examples for the Pulse layer, sending and receiving pulses with no protocol on top
* Corrected and extended library references for NEC, Pulse and the supplied remotes
* Host tests, run in CI
